# Pontelis

**Build the bridge. Automate the crossing.**

Pontelis is a small studio that builds software to automate making and publishing content.

## Projects

### Content Zavod

An automated pipeline that finds popular moments in public Twitch streams and edits each one into a short vertical video. Videos go to Pontelis's own accounts: published on YouTube and Instagram, sent to TikTok as drafts that are published by hand. Every clip credits its streamer.

[TwitchMoments on YouTube](https://www.youtube.com/@twitchmoments-e2z) · [content-zavod.pontelis.com](https://content-zavod.pontelis.com)
